# 微信扫码登录 · 接入指南

> 目标：用户点击「微信」→ 弹出微信官方二维码 → 手机微信扫码并点「确认登录」→ 电脑端自动登录，且系统内拿到的是**真实的微信身份（openid / unionid / 昵称 / 头像）**。
>
> 代码已全部写完并上线运行（`server/index.js` 的 `/api/auth/wechat/*` 四个端点 + `Login.vue` 弹层 + `OAuthCallback.vue` 中转页）。
> **唯一缺的是企业主体的资质配置**——微信开放平台不向个人主体开放「网站应用」的扫码登录能力。

---

## 一、为什么现在还没跑通真实微信登录

| 环节 | 现状 | 说明 |
| --- | --- | --- |
| 前端二维码弹层 | ✅ 已完成 | 配置齐全时展示微信官方 iframe 二维码，否则自动降级演示 |
| 服务端 code→token→userinfo | ✅ 已完成 | `sns/oauth2/access_token` + `sns/userinfo`，unionid 优先绑定 |
| 账号绑定与自动建号 | ✅ 已完成 | 生成 `wx_<openid>` 账号，二次登录直接命中 |
| 回调中转与登录态回传 | ✅ 已完成 | 302 → `/oauth/callback?token=` → 写 `ylnz_token` |
| **AppID / AppSecret** | ❌ 缺失 | 需企业主体在[微信开放平台](https://open.weixin.qq.com)创建「网站应用」并通过审核 |
| **授权回调域名** | ❌ 缺失 | 需已备案域名，且与 `redirect_uri` 完全一致 |

> 微信官方规则：网站应用（`snsapi_login`）仅支持**企业、个体工商户、政府/媒体**等非个人主体；个人主体只能申请「小程序 / 公众号」的能力，拿不到 `qrconnect` 接口。

## 二、开通步骤（拿到 AppID 后 3 分钟接入）

### 1. 申请网站应用（企业主体）

1. 登录 https://open.weixin.qq.com → 「管理中心」→「网站应用」→「创建网站应用」
2. 填写：应用名称（如「云岭农诊」）、应用简介、**应用官网**（需已备案）
3. 授权回调域填写：`你的域名`（**不带** `https://`、**不带** 路径，例如 `ylnz.example.com`）
4. 提交审核（一般 1–7 个工作日），通过后获得 **AppID** 与 **AppSecret**

### 2. 填入 `.env`

```env
# 微信开放平台网站应用
WECHAT_APP_ID=wx1234567890abcdef
WECHAT_APP_SECRET=abcdef1234567890abcdef1234567890

# 对外可访问地址（必须 https 且与后台「授权回调域」同域）
PUBLIC_BASE_URL=https://ylnz.example.com
# 若前后端分离部署，前端地址单独指定（不填则与 PUBLIC_BASE_URL 相同）
FRONT_BASE_URL=https://ylnz.example.com
```

### 3. 重启服务即可，无需改代码

```bash
npm run build && PORT=3000 node server/index.js
```

验证配置是否生效：

```bash
curl https://ylnz.example.com/api/auth/wechat/config
# 期望：{"enabled":true,"appId":"wx...","redirectUri":"https://ylnz.example.com/api/auth/wechat/callback","missing":[]}
```

`enabled: true` 后，登录页点「💬 微信」将由演示模拟**自动切换为微信官方二维码**，手机扫码确认后即真实登录。

## 三、登录链路（已实现的完整时序）

```
① 浏览器  GET /api/auth/wechat/qr
     服务端生成随机 state（5 分钟有效），返回：
     https://open.weixin.qq.com/connect/qrconnect?appid=..&redirect_uri=..&scope=snsapi_login&state=..&...
② 二维码在 iframe 内展示（或点「在新页面打开微信授权」整页跳转）
③ 用户用手机微信扫码 → 微信内点「确认登录」
④ 微信 302 → GET /api/auth/wechat/callback?code=..&state=..
     4.1 校验 state 防 CSRF，一次性删除
     4.2 code 换 access_token + openid
     4.3 拉 userinfo（unionid / nickname / headimgurl）
⑤ 服务端按 unionid（无则 openid）绑定：账号 = wx_<openid>
     未命中 → 自动建号，昵称/头像取微信资料
⑥ 302 → /oauth/callback?token=<会话令牌>
⑦ OAuthCallback.vue 写入 ylnz_token，跳回首页
     └─ 若在 iframe 内：postMessage({type:'ylnz-oauth', token}) 给父页面，父页面直接登录
```

**安全设计**

- `state` 一次性消费 + 5 分钟过期，阻断重放与 CSRF
- 令牌为无状态 HMAC 签名（`v1.<uid>.<exp>.<sig>`），服务端不存会话表
- 回传 token 仅用于一次性跳转，落地即写入 localStorage 并从 URL 清理
- iframe 通信校验 `e.origin === window.location.origin` 与 `type === 'ylnz-oauth'`

## 四、未配置时的降级行为（当前线上状态）

| 能力 | 未配置时 | 配置后 |
| --- | --- | --- |
| 微信弹层 | 展示模拟二维码 + 精确提示缺少哪几个变量 | 展示微信官方真实二维码 |
| 点击「微信」 | 可「模拟微信扫码成功」直接体验全流程 | 必须真实扫码，无法伪造 |
| 数据库 | 写入 `demo` 前缀的演示账号 | 写入 `wx_<openid>` 真实绑定账号 |

> 答辩演示建议：如企业资质尚未下来，使用登录页的 **`▦ 扫码登录`**——这是本项目自研的**真实跨设备扫码登录**（不依赖任何第三方平台资质）：手机扫二维码 → 打开确认页 → 填手机号确认 → 电脑端 1.5s 内自动登录。判定逻辑与微信扫码一致，只是身份源换成了手机号。

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 二维码区域空白 | 回调页面被 `X-Frame-Options` 拒绝 | 点弹层里的「在新页面打开微信授权」整页跳转 |
| 扫码后提示「redirect_uri 参数错误」 | `PUBLIC_BASE_URL` 与后台授权回调域不一致 / 带路径 / 用 http | 改为纯域名形式，且必须 https |
| 提示「state 已失效」 | 二维码停留超 5 分钟 | 点「刷新二维码」 |
| 提示「未配置微信开放平台」 | `.env` 变量为空 | 补齐 4 个变量后重启 |
| 拿不到 unionid | 该微信未关注同主体公众号 | 系统自动回退 openid，登录不受影响 |

## 六、附：`snsapi_login` 与公众号 / 小程序的区别

| 场景 | scope | 入口 | 本项目适用性 |
| --- | --- | --- | --- |
| **网站应用扫码（电脑端）** | `snsapi_login` | `open.weixin.qq.com/connect/qrconnect` | ✅ 当前实现，答辩电脑投屏最合适 |
| 公众号网页授权（手机微信内） | `snsapi_userinfo` | `open.weixin.qq.com/connect/oauth2/authorize` | 若后续做移动端 H5，可复用同一套绑定逻辑 |
| 小程序登录 | `code2Session` | `wx.login` | 若后续做小程序，仅需替换 4.2 那一步 |

三种渠道最终都收敛到 `wx_<openid>` 账号上，**用户资产不分裂**。
