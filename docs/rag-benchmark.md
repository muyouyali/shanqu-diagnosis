## 二、无命中兜底（防止幻觉的关键）

| 查询 | 行为 |
| --- | --- |
| 「量子纠缠波动方程」（无任何相关性） | 返回**空数组**，不强行匹配；上层用药指导 Agent 明确告知「知识库无命中」，降级为通用安全建议——**宁可不答，不编答案** |
| 空字符串 | 返回空数组 |

> 评分表中「无命中兜底讲清楚」的证据：`server/__tests__/unit.test.js` 第 3 组用例断言无命中返回空数组且不报错；工作流层 `runTreatmentAgent` 在 `pestHits` 为空时仅输出知识库标准措施并要求专家复核。

## 三、检索实现要点

- **BM25 打分**：k1=1.5，b=0.75，对病害名/别名/症状/关键词四字段分别加权（名称×3 / 别名×2.5 / 症状×2 / 关键词×1.5）
- **同义词扩展**：口语词映射（如「蔫了」→「萎蔫」，「发霉」→「霉层」），见 `SYNONYMS` 表
- **归一化输出**：`scoreNormalized = score / maxScore`，前端置信度可视化直接可用
- **可观测性**：`GET /api/retrieve?q=` 调试端点，评委可现场验证任意查询的打分明细
- **升级路径**：`retrieve()` 为纯函数接口，向量检索实现仅需替换该函数，上层零改动
