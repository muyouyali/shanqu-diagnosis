# 🌿 云岭农诊 · 山地特色经济作物病虫害多Agent诊断系统

> 全国高校 AI Web 开发挑战赛 · 参赛作品
> 聚焦云南文山三七、高原蓝莓、柑橘三种特色经济作物，面向山地散户农户与基层农技站的 AI 诊断系统

## 一、项目简介

云南山地农户居住分散、农技资源匮乏，特色经济作物病害资料稀缺，误诊误治造成严重损失。**云岭农诊**通过「拍照识别 → 多 Agent 分级诊疗 → 知识库问答」的完整闭环，让农户用一部手机就能获得专业级病虫害诊断与安全用药指导。

### 核心亮点

| 亮点 | 说明 |
|------|------|
| 🤖 **双 Agent 分级诊疗** | 初诊 Agent（多模态识图）→ 安全闸门（规则引擎）→ 用药指导 Agent（RAG 加持）三级工作流 |
| 📚 **专属 RAG 知识库** | 3 种作物 / 15 种病害 / 9 条农药安全数据，BM25+同义词扩展检索，可无缝升级向量检索 |
| 🛡️ **AI 安全可控** | 低置信度强制转人工、检疫性病害最高级警示、农药禁用黑名单硬校验、全链路免责声明 |
| 🗣️ **适老化交互** | 大字体、极简步骤、语音播报、口语化问答 |
| 📊 **农技站后台** | 病害排行 / 诊断趋势 / 区域热力 / AI 区域预警，服务基层防控决策 |
| 🔌 **统一 AI 适配层** | OpenAI 兼容协议，切换服务商（百炼/火山/智谱/GLM）只改 4 行配置 |

## 二、快速开始

### 环境要求

- Node.js ≥ 18
- pnpm（或 npm）

### 安装与运行

```bash
# 1. 安装依赖
pnpm install

# 2. 配置 AI 服务（不配置也能跑，将使用知识库降级模式）
cp .env.example .env
# 编辑 .env，填入 AI_BASE_URL / AI_API_KEY / AI_VISION_MODEL / AI_TEXT_MODEL

# 3. 开发模式（前端 5173 + API 3001 同时启动）
pnpm dev

# 4. 生产模式
pnpm build
pnpm start          # 单端口 3001 同时托管前端与 API
```

访问地址：

- 农户端 H5：`http://localhost:3001/`
- 农技站后台：`http://localhost:3001/admin`

### 服务商配置示例

```bash
# 阿里云百炼
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_API_KEY=sk-xxxx
AI_VISION_MODEL=qwen-vl-max
AI_TEXT_MODEL=qwen-plus
```

更多服务商见 `.env.example` 内注释。

## 三、功能清单

### 农户端（移动 H5）

- ✅ 拍照/相册上传（自动压缩至 1280px，控制流量与 token）
- ✅ 诊断维度补充：作物 / 海拔 / 天气 / 生育期 / 发病面积 / 症状描述
- ✅ Top3 疑似病害 + 置信度环 + 吻合症状点 + 鉴别要点
- ✅ 分级防治方案：立即行动 → 农业措施 → 药剂方案（含安全间隔期、配伍禁忌）
- ✅ AI 过程透明化：工作流各环节耗时与降级状态可视化
- ✅ RAG 农技问答：口语化提问，回答附知识库来源与相似度
- ✅ 种植档案：历史记录、恢复情况标记、AI 复盘建议
- ✅ 病害图谱：15 种病害图文速查 + 详情页
- ✅ 语音播报（Web Speech API）

### 农技站后台（PC）

- ✅ 数据看板：KPI / 诊断趋势 / 病害排行 / 作物分布 / 区域柱图 / 置信度分布
- ✅ 诊断记录：检索 / 筛选 / 详情抽屉 / 删除
- ✅ 区域预警：AI 分析 + 规则兜底四级预警（红/橙/黄/绿）
- ✅ 系统状态：AI 配置、知识库规模、模型调用指标、演示数据重置

## 五、降级设计（演示保障）

| 故障场景 | 系统行为 |
|----------|----------|
| AI 未配置 | 初诊走规则匹配，用药方案由知识库直出，前端标注「降级运行」 |
| 视觉模型超时 | 自动重试 2 次（指数退避），仍失败转规则路径 |
| 模型输出非法 JSON | 三级容错解析（围栏剥离 → 大括号截取 → 数组截取） |
| 模型推荐禁用药 | 农药黑名单硬校验，自动移除并告警 |
| 置信度 < 40% | 强制标注「建议咨询农技人员」 |

## 六、数据说明

- 知识库整理自《全国农业技术推广服务中心防治手册》、云南省植保植检站公开资料等，详见各病害条目的 `references` 字段。
- 后台初始数据为**演示种子数据**（标记 `isDemo`），模拟真实流行规律构造，可在「系统状态」页一键重置。
- 所有诊断输出均附带免责声明：「AI 诊断仅供参考，不替代专业农技人员指导」。
